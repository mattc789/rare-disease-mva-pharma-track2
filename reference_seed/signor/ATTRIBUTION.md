# SIGNOR 4.0 October 2026 official release — attribution and license

This directory contains one **losslessly gzip-compressed copy** of SIGNOR
4.0's official October 2026 stable release. It is used only if the official
SIGNOR university server is temporarily unreachable. The software always
attempts the official HTTPS source first and verifies the exact original
dataset SHA-256 on use; it never substitutes a different scientific release.
